# WebDAV FS — File Server

Turn your Android device into a powerful **WebDAV & FTP** file server.

WebDAV FS makes it easy to share, manage, and access your files on your Android phone, tablet, or TV. Launch a secure local WebDAV/FTP server in seconds and access your files from any device — PC, tablet, or smartphone — as if your phone were a network drive.

## Key features

- Full-featured **WebDAV** server for reliable file access
- Optional **FTP** mode for simple file transfers
- Choose any folder to share, including SD card, with **read-only** mode if needed
- **TLS/SSL** encryption for secure connections
- Modern, browser-based interface for easy file management
- Quick setup: set a password and start sharing immediately
- Server can start with the app or on device boot
- Themes and language options
- Phone and Android TV friendly layouts
- Lightweight, efficient, and runs smoothly in the background

## Why WebDAV FS?

Whether you want to access your files from a laptop, share documents across devices, or set up a personal file server, WebDAV FS gives you a fast, secure, and simple solution. Its WebDAV-first approach ensures compatibility with almost any device or client, while the optional FTP mode covers basic file transfer needs.

Mount or browse the share from Windows, macOS, Linux, or another phone using a WebDAV client or a regular browser.

## Perfect for

- Accessing files from Windows, Mac, Linux, or mobile devices
- Home automation setups that need file sharing
- Remote work and document management on a private local network
- Anyone who wants a private, secure Android-based file server without a cloud account
