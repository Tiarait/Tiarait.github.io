# WebDAV FS — Файловий сервер

Перетворіть свій Android або TV на швидкий та надійний локальний сервер **WebDAV & FTP**.

WebDAV FS дозволяє легко ділитися, керувати та отримувати доступ до файлів на Android або TV. Запустіть безпечний локальний WebDAV/FTP сервер за секунди та використовуйте файли з будь‑якого пристрою — ПК, Mac, Linux, планшет або смартфон — ніби телефон є мережевим диском.

## Основні функції

- Повнофункціональний **WebDAV** сервер для надійного доступу до файлів
- Додатковий режим **FTP** для простих передач файлів
- Вибір будь‑якої папки для спільного доступу (включно з SD), з опцією **лише для читання**
- Шифрування **TLS/SSL** для безпечного підключення
- Сучасний веб‑інтерфейс для легкого керування файлами
- Швидке налаштування: встановіть пароль і почніть ділитися одразу
- Сервер може стартувати з додатком або при завантаженні пристрою
- Теми та мови
- Зручні макети для телефону й Android TV
- Легкий, ефективний і стабільно працює у фоновому режимі

## Чому WebDAV FS?

Доступ до файлів локально, обмін документами між пристроями або налаштування персонального Android‑сервера. Основний режим WebDAV сумісний майже з усіма пристроями, а FTP покриває базові потреби. Швидко, надійно та зручно.

Підключайтеся з Windows, macOS, Linux або іншого телефону через WebDAV‑клієнт чи звичайний браузер.

## Підходить для

- Домашня автоматизація та мережеві пристрої
- Віддалена робота та керування документами в приватній локальній мережі
- Будь‑хто, кому потрібен приватний, безпечний та швидкий файловий сервер без хмарного акаунта
