# M3U Tools — Посібник користувача

**M3U Tools** — це Android-застосунок для імпорту, редагування, упорядкування та експорту IPTV-плейлистів у форматі M3U/M3U8. Використовуйте його, щоб виправляти назви каналів і груп, очищати дублікати, перевіряти URL потоків, оновлювати дані з віддаленого джерела та експортувати файл для свого плеєра.

Усі дані плейлистів залишаються на вашому пристрої. Застосунок не потребує облікового запису.

---

## Навіщо використовувати M3U Tools?

| Перевага | Що це означає для вас |
|-----------|------------------------|
| **Зберігає вихідний файл** | Оригінальне форматування M3U, невідомі теги та рядки на кшталт `#KODIPROP` зберігаються, де це можливо. Зміни вносяться до наявного блоку замість повного переписування. |
| **Редагування полів + Raw** | Редагуйте канали та заголовки плейлистів у структурованих формах або переходьте до необробленого тексту M3U, коли потрібен повний контроль. |
| **Великі плейлисти** | Списки каналів лишаються швидкими, оскільки застосунок не завантажує повний необроблений текст для кожного рядка списку. |
| **Плейлисти на основі URL** | Імпортуйте з URL, оновлюйте, коли постачальник змінює список, і переглядайте зміни перед застосуванням. |
| **Перевірка URL потоків** | Запускайте перевірки у фоновому режимі та фільтруйте канали за статусами OK / Помилка / Не перевірено. |
| **Потужні інструменти** | Об’єднуйте плейлисти, знаходьте дублікати, масово редагуйте, змінюйте порядок, приховуйте групи, переміщуйте або копіюйте канали між плейлистами. |
| **Експорт будь-куди** | Зберігайте у файл, діліться через інший застосунок або копіюйте згенерований текст. |

## Безкоштовна версія та M3U Tools Pro

Застосунок безкоштовний, а **M3U Tools Pro** доступний додатково (щомісячна підписка або одноразове довічне придбання в **Налаштування → Підтримка**). Ціни завантажуються з Google Play.

### Обмеження безкоштовної версії

| Плейлисти, які у вас уже є | Додавання ще одного плейлиста |
|----------------------------|-------------------------------|
| **1–3** | Безкоштовно |
| **4–6** | Може з’явитися пропозиція переглянути **коротке винагороджувальне відео**, якщо рекламу не вимкнено для цього сеансу (див. нижче) |
| **7 або більше** | Недоступно в безкоштовному тарифі — оновіть до **Pro** для необмеженої кількості плейлистів |

Ці обмеження застосовуються, коли ви **імпортуєте**, **створюєте** або **дублюєте** плейлист.

### Переваги Pro

Відкрийте **Налаштування → Підтримка → Переглянути переваги Pro**, щоб побачити повний список. Pro включає:

- **Без реклами**
- **Необмежена кількість плейлистів**
- Заплановано більше можливостей

Після придбання в Налаштуваннях відображається **Pro активний**.

### Реклама (лише безкоштовна версія)

У **Налаштування → Підтримка** можна:

- **Переглянути рекламне відео** — необов’язково; вимикає рекламу для **поточного сеансу застосунку** та пропускає відео-перевірку під час додавання плейлистів 4–6
- **Налаштування конфіденційності реклами** — керуйте згодою на рекламу, якщо цього вимагає ваш регіон (може бути недоступно поза ЄЕЗ/Великою Британією)

Користувачі Pro та окрема Pro-версія застосунку не бачать розділ Підтримка/реклама.

## Початок роботи

### Додати плейлист

На головному екрані **Плейлисти** натисніть **+ Додати плейлист** і виберіть:

1. **Імпортувати з URL** — вставте посилання `http://` або `https://`. Застосунок може перевірити URL перед імпортом. Останні URL запам’ятовуються.
2. **Імпортувати з файлу** — виберіть локальний файл `.m3u` / `.m3u8`.
3. **Порожній плейлист** — почніть з нуля та додавайте канали вручну.

Також можна відкрити файл M3U з іншого застосунку (**Поділитися** / **Відкрити за допомогою**), якщо M3U Tools доступний як обробник.

### Відкрити плейлист

Натисніть картку плейлиста, щоб відкрити **Деталі плейлиста** — список каналів із пошуком, фільтрами та діями.

Фільтруйте плейлисти на головному екрані за джерелом: **Усі**, **URL** або **Пристрій** (на основі файлу).

### Видалити плейлист

Використовуйте меню **⋮** на картці плейлиста або проведіть ліворуч (якщо дії жестами увімкнено). Вам буде запропоновано підтвердити дію — плейлист і всі його канали буде видалено назавжди.

## Деталі плейлиста

### Верхня панель

- **Пошук** — фільтрує канали за назвою, групою або URL.
- **Експорт** — експортуйте у файл, поділіться файлом або скопіюйте як текст (для дуже великих плейлистів може бути запропоновано експортувати файл замість копіювання).
- **Меню переповнення (⋮)**:
  - Відкрити за допомогою… / Перейменувати / Дублювати
  - **Оновити** — для плейлистів із URL-джерела: завантажити віддалений файл, показати попередній перегляд відмінностей, застосувати вибрані зміни
  - **Перевірити URL** / зупинити перевірку URL
  - **Знайти дублікати**
  - **Змінити порядок каналів**
  - **Переглянути необроблений M3U**
  - **Заголовок плейлиста** — редагувати блок `#EXTM3U` / `#PLAYLIST`

### Фільтри

- **Чипи груп** — фільтруйте за `group-title`; утримуйте групу, щоб перейменувати її, приховати/показати, вибрати канали або видалити групу.
- **Чипи статусу** — Усі, OK, Помилка, Перевіряється, Не перевірено, Невідомо (після перевірок URL).
- **Приховані канали** — керуються в Налаштуваннях (показувати або приховувати канали, позначені як приховані).

### Список каналів

Кожен рядок показує назву, групу, необов’язковий логотип (`tvg-logo`), тег позиції `#N` у режимі сортування та статус перевірки URL.

**Поведінку натискання** можна налаштувати в Налаштуваннях: панель дій каналу, режим вибору, відкриття у зовнішньому плеєрі або редагування.

**Дії жестами** (Налаштування → Дії жестами): проведіть праворуч, щоб редагувати, ліворуч — щоб видалити (для каналів і на екрані Плейлисти).

**Утримуйте** канал, щоб увійти в режим вибору для масових операцій.

### Режим вибору

Коли вибрано один або більше каналів:

- Масове редагування (назва, група, поля TVG, теги catchup тощо)
- Перемістити до групи / встановити позицію
- Перевірити URL для вибраних
- Приховати / показати
- Перемістити або копіювати до іншого плейлиста
- Видалити (із панеллю скасування, якщо ввімкнено)

### FAB (плаваюча дія)

- **Додати канал** — ручне введення з повним редактором полів/Raw.
- **Перевірка URL** — відкриває фонову панель перевірки URL (див. нижче).

## Редагування каналу

Відкрийте через натискання (якщо налаштовано), проведення праворуч, масове редагування або **Додати канал**.

### Вкладка Поля

Згортані розділи:

- **Основна інформація** — назва, URL потоку, група (із вибором із наявних груп).
- **Перегляд / зсув часу** — `catchup`, `catchup-days`, `catchup-source`, `timeshift` тощо.
- **Метадані TVG** — поля зіставлення EPG та URL логотипа (попередній перегляд наживо).
- **Додатково** — User-Agent, Referrer, прапорець радіо.
- **Власні теги #EXTINF** — будь-які додаткові атрибути (наприклад, `tvg-rec`, `parent-code`).

**Редагувати Raw** унизу перемикає на вкладку Raw, де поля синхронізовані з текстом M3U.

### Вкладка Raw

Редагуйте повний блок каналу (рядок `#EXTINF`, необов’язкові проміжні рядки, рядок URL). Підсвічування синтаксису полегшує читання тексту. Недійсні блоки M3U показують помилку розбору під час збереження.

Рядки між `#EXTINF` і URL (наприклад, `#KODIPROP`) зберігаються з оригінального імпорту, коли ви редагуєте через Поля; за потреби змініть їх у **Raw**.

### Незбережені зміни

Якщо ви щось змінили, **змахування панелі вниз** або її закриття запитує **Відхилити зміни?** — **Продовжити редагування** залишає панель відкритою, **Відхилити** закриває без збереження.

Керується через **Налаштування → Підтвердження безпеки** (так само для заголовка плейлиста — див. нижче).

## Заголовок плейлиста

Редагуйте блок перед першим `#EXTINF`:

- Назва плейлиста (`#PLAYLIST`, `playlist-name` у `#EXTM3U`)
- URL EPG (`x-tvg-url`, `url-tvg`, `tvg-url`)
- Зсув часу (`tvg-shift`)
- Логотип плейлиста
- Catchup/timeshift у заголовку
- Власні теги `#EXTM3U`
- **Шаблони заголовка** — швидкі шаблони (наприклад, catchup у стилі Xtream)
- Вкладки **Поля / Raw** — така сама схема, як під час редагування каналу

У **Raw** вводьте звичайний синтаксис атрибутів M3U, наприклад:

```text
#EXTM3U x-tvg-url="https://example.com/epg.xml"
#PLAYLIST:Мій список
```

Закриття панелі заголовка з незбереженими змінами показує такий самий діалог **Відхилити зміни?**, як і під час редагування каналу (коли ввімкнено підтвердження безпеки).

## Зміна порядку та сортування

**Змінити порядок каналів** (меню переповнення):

- Перетягуйте маркери, щоб переміщувати рядки
- Натисніть канал → **Встановити позицію**
- **Параметри сортування** — попередньо перегляньте сортування за назвою або групою (А→Я / Я→А); початковий порядок відновлюється зі збереженого, доки ви не натиснете ✓ для збереження

Незбережені зміни порядку запитують підтвердження перед виходом.

## Пошук дублікатів

Виявляйте дублікати **за назвою**, **за URL** або **назва + URL**.

- Виберіть зайві записи вручну та видаліть
- **Залишити лише перший** — видаляє дублікати, зберігає перший канал у кожній групі (за збереженим порядком)

## Оновити плейлист (джерела URL)

1. Меню → **Оновити** завантажує віддалений M3U.
2. **Переглянути оновлення плейлиста** показує хеш/розмір файлу, зміну кількості каналів і вкладки: Додано / Видалено / Змінено.
3. Натисніть змінений канал, щоб побачити відмінності за кожним полем.
4. Режим застосування:
   - **Замінити весь плейлист**
   - **Лише URL**
   - **Додати лише нові**
   - **Оновити URL і додати нові**
   - **Пропустити оновлення**

Поки застосовуються зміни, відображається діалог перебігу.

## Перевірка URL

Запускайте з вибору, меню переповнення або FAB **Перевірка URL** у деталях плейлиста.

**Панель налаштування:**

- **Критерії успіху** — Строгий 2xx (рекомендовано для IPTV), Доступний (не 404) або Будь-яка відповідь HTTP
- **Метод перевірки** — спочатку спробувати HEAD, із резервним GET (з необов’язковим Range)
- **Тайм-аут** — для кожного сеансу (типово 10 секунд; типовий час можна налаштувати в параметрах застосунку, де це доступно)

Перевірки виконуються **всередині застосунку**, поки він відкритий (або в пам’яті протягом сеансу):

- Натисніть FAB **Перевірка URL** ще раз, щоб побачити активні й завершені перевірки
- **Призупинити / Продовжити**, **Згорнути** або вилучити сеанс зі списку
- Відкрийте сеанс, щоб переглядати канали за статусом і редагувати окремі записи
- Рядки каналів оновлюються зі статусом OK / Помилка / Перевіряється / Невідомо

Для перевірки URL **немає системних сповіщень** — відкрийте застосунок і скористайтеся кнопкою перевірки URL, щоб побачити перебіг і результати.

## Екран необробленого M3U

**Переглянути необроблений M3U** відкриває повноекранний редактор із двома режимами:

| Режим | Вміст |
|------|-------|
| **Згенерований** | Створений із ваших змін у базі даних (готовий до експорту) |
| **Вихідний файл** | Оригінальний файл, збережений під час імпорту (не змінюється редагуванням) |

Можливості: пошук із переходом між збігами, статистика рядків/каналів, збереження згенерованого тексту назад у плейлист.

Створення дуже великого згенерованого файлу показує діалог перебігу.

## Експорт і поширення

У деталях плейлиста → Експорт:

- **Експортувати у файл…** — системний діалог збереження
- **Поділитися файлом…** — надіслати `.m3u` до іншого застосунку
- **Копіювати як текст** — буфер обміну (застосовується обмеження розміру)

Експортовані файли використовують збережене форматування, коли застосунок зберіг необроблений текст кожного каналу під час імпорту.

---

## Об’єднати плейлисти

На екрані **Плейлисти** утримуйте або увійдіть у режим вибору, виберіть **2+ плейлисти**, потім **Об’єднати плейлисти**.

- Ціль: новий об’єднаний плейлист або наявний
- Необов’язково: видалити вихідні плейлисти після об’єднання (канали завжди копіюються, а не переміщуються)
- Підсумок результату: додано, оновлено, пропущено, копії конфліктів

## Налаштування

Відкрийте за допомогою значка шестерні на екрані Плейлисти.

### Тема

Системна, світла або темна.

### Мова

Системна за замовчуванням, English, Русский, Українська. Зміна мови перезапускає activity.

### Канали

| Налаштування | Опис |
|--------------|------|
| **Дії жестами** | Проведення праворуч = редагувати, проведення ліворуч = видалити |
| **Показувати логотип каналу** | Мініатюра `tvg-logo` у списку |
| **Показувати приховані канали** | Включати канали, позначені як приховані |

### Дія натискання на канал

| Варіант | Поведінка |
|---------|-----------|
| **Дії каналу** | Відкриває панель дій (типово); меню ⋮ приховано |
| **Вибрати канал** | Входить у режим вибору |
| **Відкрити в плеєрі…** | Передає URL потоку до зовнішнього застосунку |
| **Редагувати** | Відкриває панель редагування |

### Поведінка

| Налаштування | Опис |
|--------------|------|
| **Підтвердження безпеки** | Підтверджувати видалення, відхилення незбережених змін (канал, заголовок плейлиста, масове редагування) та подібні дії |
| **Тактильний відгук** | Вібрація під час вибору й проведення |

### Підтримка (безкоштовна версія)

| Елемент | Опис |
|---------|------|
| **M3U Tools Pro** | Щомісячна підписка або довічна купівля; ціни з Google Play |
| **Переглянути переваги Pro** | Повний список переваг Pro |
| **Переглянути рекламне відео** | Необов’язково; вимикає рекламу для цього сеансу |
| **Налаштування конфіденційності реклами** | Згода на рекламу (де застосовно) |

### Про застосунок

| Елемент | Опис |
|---------|------|
| **Зв’язатися** | Відкриває застосунок електронної пошти (перед виходом із застосунку показується підтвердження) |
| **Політика конфіденційності** | Відкривається у браузері або показує підсумок у застосунку |
| **Посібник користувача** | Відкриває цей посібник онлайн (підтвердження перед відкриттям браузера) |
| **Версія** | Установлена версія застосунку |

Посилання та електронна пошта запитують **Вийти із застосунку?** перед відкриттям зовнішнього застосунку або браузера.

### Небезпечна зона

**Скинути всі дані** — видаляє всі плейлисти, кешовані файли M3U, кеш зображень, зупиняє перевірки URL і відновлює типові налаштування. Дію неможливо скасувати.

---

## Поради та обмеження

- **Застосунок-плеєр** — M3U Tools редагує плейлисти; він не відтворює потоки самостійно (окрім запуску URL в іншому застосунку).
- **Попередження розбору** — якщо деякі рядки не вдалося імпортувати, діалог містить номери рядків; коректні канали все одно зберігаються.
- **Скасування** — після видалення каналів або плейлистів унизу екрана може з’явитися панель скасування.
- **Приватні дані** — плейлисти можуть містити облікові дані в URL. Базу даних і файли M3U типово виключено з хмарного резервного копіювання.
- **Дуже великі плейлисти** — режим перегляду оптимізований; режим зміни порядку завантажує весь список один раз.
- **Мережа** — для імпорту, оновлення, перевірки URL і попереднього перегляду логотипа потрібен інтернет для віддалених URL. Використовуйте лише джерела, яким довіряєте.
- **Ранній випуск** — деякі можливості ще можуть змінюватися; зворотний зв’язок вітається через Зв’язатися в Налаштуваннях.

## Швидка довідка — підтримувані можливості M3U

### Заголовок плейлиста

`#EXTM3U`, `#PLAYLIST`, URL EPG, `tvg-shift`, URL логотипів, атрибути catchup/timeshift, власні теги заголовка.

### Запис каналу

`#EXTINF` зі стандартними та власними атрибутами, URL потоку, збережені проміжні рядки, catchup/timeshift для каналу, прапорець User-Agent / Referrer / радіо.

## Підтримка

Запитання та відгуки: **Налаштування → Про застосунок → Зв’язатися** (`tiar.develop@gmail.com`).

Відомості про конфіденційність: **Налаштування → Про застосунок → Політика конфіденційності**.

**Версія:** див. **Налаштування → Про застосунок** (APK-збірки мають назву `M3U_TOOLS_<version>_<type>.apk`).
