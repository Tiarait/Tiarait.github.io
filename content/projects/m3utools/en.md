# M3U Tools — IPTV Playlist Editor

M3U Tools is a powerful **IPTV playlist editor** for Android. Import, edit, organize, validate, and export **M3U / M3U8** playlists while preserving important metadata and original formatting whenever possible.

Whether you maintain a small personal channel list or a large IPTV playlist with thousands of entries, M3U Tools provides fast and efficient tools to keep everything organized.

All playlist data stays on your device. The app does not require an account.

## Features

- Import local M3U and M3U8 playlists
- Import playlists directly from a URL
- Refresh URL-based playlists when the provider updates them
- Review detected changes before applying updates
- Edit channel names, groups, logos, TVG metadata, and stream URLs
- Edit playlist headers and custom tags
- Switch between structured editing and raw M3U text
- Merge multiple playlists into one
- Find and remove duplicate channels
- Bulk edit channels and metadata
- Move or copy channels between playlists
- Reorder channels and groups
- Hide groups for easier navigation
- Export playlists to files
- Share playlists with other apps
- Copy generated M3U text

## Stream URL checker

Verify stream availability directly from the app using background URL checks (HEAD/GET). Filter channels by **OK / Error / Unchecked**. This helps identify broken streams before exporting your playlist.

## Optimized for large playlists

Large channel lists remain responsive thanks to an efficient interface that avoids loading unnecessary raw playlist content for every item. Browse mode stays light; reorder mode loads the full list when you need it.

## Why it stands out

| Advantage | What it means for you |
|-----------|------------------------|
| Preserves your source file | Original M3U formatting, unknown tags, and lines like `#KODIPROP` are kept where possible |
| Fields + raw editing | Structured forms for everyday edits, or full raw text when you need control |
| URL playlists | Import, refresh, and review provider updates before applying |
| Power tools | Merge, duplicates, bulk edit, reorder, hide groups, move/copy between lists |

## Privacy first

Playlists may contain credentials in URLs. All playlist data remains on your device. Database and M3U files are excluded from cloud backup by default. No account is required.

## Tips

- M3U Tools **edits** playlists — it does not play streams itself (you can still open a URL in another app)
- Free version with optional **M3U Tools Pro** for unlimited playlists
- Only import remote sources you trust
