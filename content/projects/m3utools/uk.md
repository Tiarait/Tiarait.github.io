# M3U Tools — IPTV редактор плейлистів

M3U Tools — потужний редактор **M3U‑** та **M3U8‑**плейлистів для IPTV на Android. Імпортуйте, редагуйте, упорядковуйте, перевіряйте та експортуйте плейлисти, зберігаючи метадані й початкове форматування, коли це можливо.

Незалежно від того, чи керуєте ви невеликим списком каналів або великим IPTV‑плейлистом із тисячами записів, M3U Tools надає швидкі та зручні інструменти для підтримки ваших плейлистів у порядку та актуальному стані.

Усі дані плейлистів залишаються лише на вашому пристрої. Обліковий запис не потрібний.

## Можливості

- Імпорт локальних M3U‑ та M3U8‑плейлистів
- Імпорт плейлистів за URL
- Оновлення плейлистів за URL після змін у провайдера
- Попередній перегляд виявлених змін перед оновленням
- Редагування назв каналів, груп, логотипів, TVG‑метаданих і URL потоків
- Редагування заголовків плейлистів і власних тегів
- Перемикання між структурованим редактором і вихідним текстом M3U
- Об’єднання кількох плейлистів в один
- Пошук і видалення дублікатів каналів
- Масове редагування каналів і метаданих
- Переміщення та копіювання каналів між плейлистами
- Зміна порядку каналів і груп
- Приховування груп для зручнішої навігації
- Експорт плейлистів у файли
- Надсилання плейлистів до інших застосунків
- Копіювання згенерованого тексту M3U

## Перевірка URL потоків

Перевіряйте доступність потоків безпосередньо в застосунку за допомогою фонової перевірки URL (HEAD/GET). Фільтруйте канали за **OK / Error / Unchecked**. Це допоможе швидко виявити недоступні або несправні потоки перед експортом плейлиста.

## Оптимізовано для великих плейлистів

Навіть плейлисти з тисячами каналів працюють швидко та плавно. Інтерфейс не підвантажує зайвий raw‑текст для кожного рядка; режим зміни порядку завантажує повний список лише коли він потрібен.

## Чим вирізняється

| Перевага | Що це дає |
|----------|-----------|
| Зберігає вихідний файл | Оригінальне форматування M3U, невідомі теги та рядки на кшталт `#KODIPROP`, де можливо |
| Поля + сирий текст | Структуровані форми для щоденних правок або повний raw‑текст для повного контролю |
| URL‑плейлисти | Імпорт, оновлення та перегляд змін від провайдера перед застосуванням |
| Power‑інструменти | Merge, дублікати, bulk edit, reorder, hide groups, move/copy між списками |

## Конфіденційність

У URL плейлистів можуть бути облікові дані. Усі дані лишаються на пристрої. База даних і файли M3U за замовчуванням виключені з хмарного бекапу. Обліковий запис не потрібний, зайві дані не збираються.

## Поради

- M3U Tools **редагує** плейлисти — сам потоки не відтворює (URL можна відкрити в іншому застосунку)
- Безкоштовна версія та опційний **M3U Tools Pro** для необмеженої кількості плейлистів
- Імпортуйте remote‑джерела лише з довірених місць
