# Universal Bot

[Universal Bot](https://t.me/poibot) (`@POI_bot`) is an AI-powered **Telegram** bot for everyday utilities and media work in one chat.

It is a multi-language bot for math calculations, media downloads, audio/video processing, Telegram message parsing, and chat info. It supports custom commands, lambda-style functions, unit conversions, and percentage calculations, and integrates with social media (TikTok, Instagram, Threads) for direct media access.

Built with **Python**, **asyncio**, and the Telegram API.

## What it can do

- Math, percentages, unit conversions, and custom / lambda-style commands
- Media access from social networks such as TikTok, Instagram, and Threads
- Audio and video processing helpers
- Telegram message parsing and chat information tools
- Multi-language replies
- AI chat alongside the utility commands

## Who it is for

- People who want a single Telegram bot for “quick calculate / convert / fetch media” tasks
- Chats that need lightweight media helpers without leaving Telegram
- Developers who want a Python + asyncio Telegram bot as a starting point (see Docker deploy docs)

## Stack

Python · Asyncio · Telebot · REST API
