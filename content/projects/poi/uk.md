# Universal Bot

[Universal Bot](https://t.me/poibot) (`@POI_bot`) — Telegram‑бот на базі ШІ для повсякденних утиліт і роботи з медіа в одному чаті.

Це багатомовний бот для математичних розрахунків, завантаження медіа, обробки аудіо/відео, парсингу повідомлень Telegram та інформації про чат. Підтримує кастомні команди, lambda‑подібні функції, конвертації одиниць і відсотки, інтегрується з соцмережами (TikTok, Instagram, Threads) для прямого доступу до медіа.

Написаний на **Python**, **asyncio** і Telegram API.

## Що вміє

- Математика, відсотки, конвертації одиниць і кастомні / lambda‑подібні команди
- Доступ до медіа з мереж на кшталт TikTok, Instagram і Threads
- Хелпери для обробки аудіо та відео
- Парсинг повідомлень Telegram і інструменти інформації про чат
- Багатомовні відповіді
- AI‑чат поруч із утилітарними командами

## Для кого

- Ті, хто хоче одного Telegram‑бота для «швидко порахувати / конвертувати / стягнути медіа»
- Чати, яким потрібні легкі медіа‑хелпери без виходу з Telegram
- Розробники, яким потрібен старт на Python + asyncio Telegram‑боті (див. Docker‑документацію)
