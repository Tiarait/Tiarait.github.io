# DevSurf — Web Inspector

DevSurf is a mobile web browser built on the standard Android **WebView**, designed for developers, testers, and power users. With built-in developer tools and flexible browsing features, you can inspect, debug, and test websites directly on your device without switching to a desktop.

## Key features

- **Developer tools** — Inspect page elements, execute or inject JavaScript, and view console logs in real time. Debug websites directly from your phone.
- **Multiple tabs** — Manage multiple websites at once with an intuitive tab interface. Tabs are saved when you leave the app.
- **Customizable settings** — Configure browser behavior to match your workflow. Control JavaScript, page layout, and other browsing options.
- **Built-in ad blocker** — Browse faster and with fewer distractions. Per-site controls and “block element on site” for custom filter rules.
- **Custom user agents** — Switch user agents to test responsive layouts or simulate different browsers and devices.
- **Screenshots** — Capture the visible page or a full-page shot (depending on settings).
- **Fast & lightweight** — Optimized for speed and efficient resource usage, even with multiple tabs open.
- **Privacy-focused** — Developer logs, console output, and browsing data remain on your device. No unnecessary tracking or data collection.

## Who it is for

Whether you are a front-end developer, QA engineer, web designer, or simply curious about how websites work on real hardware (including low-end phones and TV sticks), DevSurf brings essential web development tools to Android in a lightweight browser.

Typical uses:

- Checking layout and JS bugs on a real device without USB debugging every time
- Injecting scripts and reading console output in the field
- Testing user-agent / responsive behavior
- Browsing with an ad blocker while keeping DevTools one tap away
