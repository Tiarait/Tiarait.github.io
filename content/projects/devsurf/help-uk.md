# DevSurf — Посібник користувача

DevSurf — це мобільний браузер, створений для веброзробників. Він використовує системний Android WebView і додає вбудовані DevTools, блокувальник реклами та допоміжні засоби налагодження.

Цей посібник пояснює, як переглядати вебсторінки, користуватися DevTools, керувати блокувальником реклами та змінювати налаштування.

---

## Швидкий початок

1. Відкрийте DevSurf і прийміть вітальний екран.
2. Торкніться **рядка адреси** вгорі, щоб ввести URL або пошуковий запит.
3. Переглядайте сторінки як у будь-якому іншому браузері: перемикайтеся між вкладками свайпами, користуйтеся кнопками назад/уперед, потягніть униз для оновлення.
4. Торкніться **значка термінала** на верхній панелі, щоб відкрити **DevTools**.
5. Торкніться **меню (⋮)**, щоб отримати доступ до інших дій: історії, знімків екрана, блокування реклами, налаштувань.

---

## Головний екран

### Рядок адреси

- Торкніться його, щоб відкрити повноекранне поле пошуку/введення URL.
- Пропозиції надходять з історії вебперегляду, історії пошуку та вибраної пошукової системи.
- Натисніть **Search** або **Open**, щоб перейти на сторінку.

### Кнопки верхньої панелі

| Кнопка | Призначення |
|--------|----------------|
| **Terminal** | Відкрити або закрити DevTools (нижню панель) |
| **Кількість вкладок** | Відкрити перемикач вкладок |
| **Menu (⋮)** | Меню браузера (навігація, інструменти, налаштування) |

### Вкладки

- Торкніться кількості вкладок, щоб переглянути всі відкриті вкладки у сітці.
- Торкніться **New tab**, щоб відкрити ще одну вкладку.
- Проведіть ліворуч/праворуч по області сторінки, щоб перемикатися між вкладками.
- Закрийте вкладку в перемикачі вкладок.
- Вкладки зберігаються, коли ви виходите з програми. За нестачі пам’яті неактивні вкладки можуть бути вивантажені з RAM (ви побачите сповіщення).

### Потягніть для оновлення

Якщо це ввімкнено в Налаштуваннях, потягніть сторінку вниз, щоб перезавантажити її.

---

## Меню браузера

Відкрийте меню кнопкою **⋮** на верхній панелі.

### Рядок навігації

- **Back** / **Forward** — історія сторінок у поточній вкладці
- **Info** — відомості про сторінку (URL, безпека, JavaScript, cookies, User-Agent)
- **Refresh** / **Stop** — перезавантажити або зупинити завантаження

### Інструменти та дії

| Пункт | Опис |
|------|-------------|
| **Eruda ON/OFF** | Показати або приховати консоль Eruda на сторінці (лише якщо Eruda ввімкнено в Налаштуваннях) |
| **Blocked..** | Керування блокувальником реклами для сайту та список заблокованих запитів (лише якщо блокувальник реклами ввімкнено) |
| **Block element on site** | Торкніться елемента на сторінці, щоб заблокувати його власним правилом фільтра |
| **Save as screenshot** | Зробити знімок видимої частини сторінки або всієї сторінки (див. Налаштування → JS full screenshot) |
| **Reload & clear** | Перезавантажити сторінку та очистити дані сайту (cookies, сховище) для цього сайту |
| **History** | Історія вебперегляду та пошуку |
| **Settings** | Налаштування програми |
| **Exit** | Закрити програму |

## Меню довгого натискання (посилання та зображення)

Натисніть і утримуйте посилання або зображення на сторінці:

- **Copy link** / **Copy image link**
- **Open in new tab**
- **Share**
- **Open in external browser**
- **Inspect element** — відкриває DevTools на вкладці Elements і запускає вибір елемента
- **Download** — зберігає файл у Downloads (на старіших версіях Android може знадобитися дозвіл на сховище)

## DevTools

DevTools — це нижня панель з інструментами розробника, подібними до інспекторів у браузерах для настільних комп’ютерів.

### Як відкрити DevTools

1. Торкніться **значка термінала** на верхній панелі, або
2. Натисніть і утримуйте посилання/зображення → **Inspect element**

### Керування панеллю

- **Перетягуйте маркер** угорі, щоб змінити висоту панелі.
- Використовуйте **повзунок прозорості**, щоб зробити панель прозорішою.
- Перемикайтеся між вкладками: **Console**, **Network**, **Elements**, **Js Injector** (вкладки можна вмикати/вимикати в Налаштування → DevTools).

---

### Вкладка Console

Показує повідомлення зі сторінки (`console.log`, помилки, попередження).

**Що можна робити:**

- Читати вивід консолі сторінки
- Фільтрувати за **Errors**, **Warnings**, **Info**, **Logs**
- Вводити JavaScript у поле введення та натискати **Run**, щоб виконати код на сторінці
- Відкривати **Console history**, щоб повторно виконувати попередні команди
- **Attach file**, щоб виконати файл JavaScript на сторінці

---

### Вкладка Network

Показує мережеві запити, виконані сторінкою.

**Що можна робити:**

- Переглядати метод, статус, тип, розмір і час для кожного запиту
- Торкнутися запиту, щоб відкрити відомості: заголовки, payload, тіло відповіді
- Вмикати або вимикати кешовані запити

**Порада:** Для зображень, скриптів і стилів увімкніть **Proxy all resources** у Налаштування → DevTools. Це збирає більше даних, але уповільнює вебперегляд.

---

### Вкладка Elements

DOM-інспектор: вибирайте елементи, переглядайте стилі, редагуйте вбудований CSS, блокуйте елементи для рекламного фільтра.

**Що можна робити:**

- **Refresh DOM** — отримати поточне дерево DOM
- **Save DOM** — експортувати повний DOM як файл HTML
- **Wrap lines** — увімкнути або вимкнути перенесення довгих рядків у дереві DOM (за замовчуванням вимкнено; якщо перенесення вимкнено, довгі рядки прокручуються горизонтально). Застосовується до головного дерева та підвкладки **View** у відомостях про вузол.
- **Pick element** — торкніться елемента на сторінці, щоб вибрати його в дереві (за можливості використовується текст під місцем торкання)
- Переглядати дерево DOM і відомості про вузол (тег, атрибути, текст, дочірні елементи)
- Вкладка **View** — переглянути піддерево як HTML; вкладка **Styles** — переглянути та редагувати вбудовані стилі
- **Highlight**, **Scroll to**, зберегти або скопіювати HTML
- **Block element** — додати косметичне правило блокування реклами для вибраного елемента

> Пошук DOM на панелі Elements тимчасово вимкнено.

---

### Пошук на сторінці

Переглядаючи сторінку, використовуйте панель пошуку (з інтерфейсу браузера), щоб шукати текст на сторінці. DevSurf використовує пошук на основі JavaScript, який краще працює на складних сайтах (зокрема з shadow DOM), ніж вбудований пошук WebView.

---

### Вкладка Js Injector

Керуйте користувацькими скриптами, що виконуються на вебсторінках.

**Що можна робити:**

- Створювати, редагувати, імпортувати та видаляти скрипти JavaScript
- Вмикати або вимикати **Auto-inject** для кожного скрипту (скрипти запускаються автоматично під час завантаження сторінки)
- Скрипти зберігаються на вашому пристрої

---

## Eruda (консоль на сторінці)

Eruda — це окрема мобільна консоль налагодження, що з’являється **всередині вебсторінки** (не на панелі DevTools).

- Увімкніть або вимкніть її в **Налаштування → Developer → Eruda**
- Або використовуйте **Menu → Eruda ON/OFF** під час вебперегляду
- Корисно для швидких перевірок на будь-якому сайті без відкриття панелі DevTools

---

## Блокувальник реклами

DevSurf містить вбудований блокувальник реклами (подібний до списків фільтрів для браузерів настільних комп’ютерів).

### Глобальний перемикач

**Налаштування → Privacy & Security → Ad blocker** — увімкніть або вимкніть блокування для всіх сайтів.

### Списки фільтрів

**Налаштування → Privacy & Security → AdBlock filters**

- DevSurf завантажує **EasyList** під час першого запуску.
- Можна додавати інші підписки на фільтри (URL), завантажувати, оновлювати, перейменовувати або видаляти їх.
- **Import from file** — додати список фільтрів із вашого пристрою.
- **Custom filter** — створювати власні правила або вмикати/вимикати їх.
- **Edit rules** — переглядати або редагувати правила фільтра (дуже великі фільтри можуть бути доступні лише для перегляду).

### Керування для окремого сайту

**Menu → Blocked..**

- Переглядайте, скільки запитів заблоковано на поточному сайті
- Увімкніть або вимкніть блокувальник реклами лише для поточного вебсайту
- Переглядайте список заблокованих URL

### Заблокувати елемент вручну

1. Переконайтеся, що **Ad blocker** і **JavaScript** увімкнено.
2. **Menu → Block element on site**
3. Торкніться реклами або елемента на сторінці
4. Підтвердьте — правило буде додано до вашого власного фільтра, а елемент приховано

Також можна блокувати елементи на вкладці **Elements** у DevTools (збірки для налагодження).

## Історія

**Menu → History**

Дві вкладки:

- **Web** — відвідані сторінки
- **Search** — введені пошукові запити

Торкніться елемента, щоб відкрити його. Проведіть пальцем або скористайтеся видаленням, щоб прибрати елементи. Використовуйте **Clear**, щоб очистити історію всієї вкладки.

Щоб очистити всю історію одразу: **Налаштування → Data → Clear all history**.

---

## Завантаження

- Натисніть і утримуйте посилання → **Download**
- Або дозвольте сторінці запустити завантаження (діалог вибору файлу)
- Файли зберігаються в системній папці **Downloads**
- На Android 9 і старіших версіях може знадобитися дозвіл на сховище

---

## Знімки екрана

**Menu → Save as screenshot**

- Якщо **JS full screenshot** вимкнено: зберігається лише видима частина сторінки.
- Якщо **JS full screenshot** увімкнено (за замовчуванням): зберігається вся прокручувана сторінка.

Після завершення створення знімка відкривається попередній перегляд. Збереження до галереї ще не реалізовано — знімок екрана можна переглянути в діалозі попереднього перегляду.

Відкрийте **Menu → Settings**.

### Підтримка (лише безплатна версія)

| **Blur effects** | Розмивати фон, коли відкрито рядок адреси або налаштування |

## Налаштування WebView (розширені)

**Налаштування → Browser → WebView settings**

Ці параметри керують низькорівневою поведінкою WebView. Змінюйте їх, лише якщо знаєте, що вам потрібно.

**Сховище:** DOM Storage, доступ до файлів, доступ до контенту

**Відображення:** масштабування, вбудовані елементи керування масштабуванням, широкий viewport, завантаження з оглядом, автоматичний розмір тексту, алгоритмічне затемнення (Android 13+)

**Поведінка:** для медіа потрібен жест, спливні вікна JavaScript

**Безпека:** режим змішаного вмісту (завжди дозволяти / ніколи не дозволяти / сумісність)

**Кеш:** режим кешу (за замовчуванням, спочатку кеш, без кешу, лише кеш)

## Усунення несправностей

### WebView не працює

Якщо ви бачите помилку «WebView provider»:

1. Установіть або оновіть **Android System WebView** чи **Google Chrome**
2. У **Параметрах розробника** Android виберіть реалізацію WebView
3. Спробуйте очистити кеш DevSurf (не всі дані) у системних налаштуваннях програм
4. Перезапустіть пристрій

### Сторінка відображається неправильно

- Спробуйте перемкнути **Desktop mode** у Налаштуваннях
- Перевірте, чи ввімкнено **JavaScript**
- Спробуйте **Reload & clear** у меню, щоб скинути дані сайту

### Блокувальник реклами надто агресивний

- **Menu → Blocked..** → вимкніть для цього сайту
- Або відредагуйте правила **Custom filter** у AdBlock filters

### Панель копіювання з’являється не там

Якщо системна панель **Copy** відображається вгорі екрана, а не поруч із виділенням, вимкніть **Налаштування → Privacy & Security → Copy selection only**. Цей суворий режим прибирає зазначення сайту зі скопійованого тексту, але може порушити позиціювання панелі на деяких сторінках. Коли його вимкнено, виділення все ще працює, якщо ввімкнено **Allow copy & selection**; сайти можуть додавати власний текст (наприклад, URL джерела) до буфера обміну.

### Вкладка Elements у DevTools відсутня

Переконайтеся, що **Налаштування → DevTools → DevTools: Elements** увімкнено.

---

## Чого DevSurf ще не має

- Закладок
- Збереження знімків екрана до галереї (лише попередній перегляд)
- Синхронізації між пристроями

---

## Примітка щодо конфіденційності

DevSurf завантажує вебвміст із сайтів, які ви відвідуєте. Автор програми не відповідає за зовнішній вебвміст. Історія вебперегляду та налаштування зберігаються локально на вашому пристрої.
