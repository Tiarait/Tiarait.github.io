# HTTP FS — Файловий / WebDAV сервер

Перетворіть ваш Android телефон, планшет або TV у швидкий і надійний **файловий сервер**.

HTTP FS дозволяє передавати файли через Wi‑Fi за допомогою локального **HTTP** або **WebDAV** сервера — без кабелів, додаткових додатків на стороні отримувача та інтернету.

Простий спосіб обміну файлами між Android‑пристроями, віддаленого керування сховищем та швидкої передачі фото, відео, документів та інших файлів.

## Працює на телефонах, планшетах та Android TV

Запустіть сервер прямо на TV, щоб завантажувати фільми, музику або файли з комп’ютера чи телефону через будь‑який браузер в одній Wi‑Fi мережі. Повна підтримка пульта Android TV робить це зручним не лише для телефону, а й як файловий хаб у вітальні.

## Як працює

1. Запустіть сервер по Wi‑Fi — або створіть мобільну точку доступу
2. Виберіть будь‑яку папку на пристрої
3. Поділіться згенерованим посиланням або QR‑кодом
4. Інші користувачі одразу отримають доступ через браузер

Ідеально для швидкої передачі файлів між Android‑пристроями без USB і без хмари.

## Функції

- Локальний **HTTP** та **WebDAV** сервер
- Сучасний веб‑інтерфейс для керування файлами
- Швидка передача без USB кабелів
- Завантаження, скачування, перейменування, видалення та переміщення файлів
- Створення та скачування ZIP архівів
- Парольний захист для безпечного доступу
- Контроль часу сесії
- Опційний **SSL (HTTPS)**
- Підтримка **RSS** API
- Прості логи доступу — хто користується сервером
- Запуск сервера при старті пристрою
- Стартовий файл (наприклад `index.html`)
- Багатомовний інтерфейс
- Працює офлайн (тільки локальна мережа)
- Легкий, простий та швидкий
- Безкоштовно в Google Play; **HTTP FS Pro** без реклами

## Для кого

- Перекинути фото й відео з телефону на ноутбук в одній Wi‑Fi мережі
- Поділитися папкою документів вдома, в офісі чи в класі
- Запустити медіа‑папку на Android TV для інших пристроїв у LAN
- Ті, хто хоче приватний локальний сервер замість завантаження в хмару
