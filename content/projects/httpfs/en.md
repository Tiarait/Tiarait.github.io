# HTTP FS — File & WebDAV Server

Turn your Android phone, tablet, or TV device into a fast and reliable **file server**.

HTTP FS lets you transfer files over Wi‑Fi using a local **HTTP** or **WebDAV** server — no cables, no apps on the receiving side, and no internet connection required.

It’s an easy way to share files between Android devices, manage storage remotely, or quickly transfer photos, videos, documents, and more.

## Works on phones, tablets, and Android TV

Launch the server directly on your TV to upload movies, music, or files from your computer or phone through any browser on the same Wi‑Fi network. Full support for Android TV remotes makes it practical as a living‑room file hub — not only a phone utility.

## How it works

1. Start the server on Wi‑Fi — or create a mobile hotspot
2. Choose any folder on your device
3. Share the generated link or QR code
4. Other users instantly get access through their browser

Perfect for fast file transfer between Android devices without USB cables or cloud accounts.

## Features

- Local **HTTP** and **WebDAV** server
- Modern web interface for browsing and managing files
- Fast Wi‑Fi file sharing without USB cables
- Upload, download, rename, delete, and move items
- Create and download ZIP archives
- Password protection for secure access
- Session time controls
- Optional **SSL (HTTPS)**
- **RSS** API support
- Simple access logs — see who is using the server
- Server can start on device boot
- Choose a starting file (for example `index.html`)
- Multi-language UI
- Works completely offline (local network only)
- Lightweight, simple, and fast
- Free on Google Play; **HTTP FS Pro** removes ads

## Who it is for

- Moving photos and videos off a phone to a laptop on the same Wi‑Fi
- Sharing a folder of documents in a classroom, office, or at home
- Running a small media folder on Android TV for other devices on the LAN
- Anyone who wants a private local server instead of uploading to the cloud
