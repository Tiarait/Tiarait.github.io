# AI Muse

AI Muse — Android‑додаток для генерації зображень через кілька **AI API** в одному місці.

Він підтримує кілька джерел генерації, даючи широкий вибір для створення візуальних робіт. Інтерфейс розрахований на простоту: налаштували параметри, запустили генерацію, переглянули результат — без стрибків між сайтами й акаунтами для кожного бекенда.

У додатку також є галерея з прикладами запитів і зображень з різних джерел, щоб швидко надихнутися й почати створювати.

Чи потрібні вам чернетки для креативного проєкту, чи просто хочеться експериментувати з AI‑генерацією на телефоні — AI Muse збирає інструменти в одному Android‑клієнті.

## Що всередині

- Кілька бекендів генерації для різних стилів і експериментів
- Керування промптами та параметрами в одному UI
- Галерея прикладів запитів і результатів
- Зручний сценарій створення прямо на пристрої

## Технічний стек

Kotlin · Android · Jetpack Compose · MVVM · Room · REST API

## Статус

Проєкт **більше не підтримується активно**. Лишається як опублікований експеримент / архів ідеї — корисний як portfolio‑кейс і референс, а не як продукт із регулярними оновленнями.
