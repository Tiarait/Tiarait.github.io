# AI Muse

AI Muse is an Android app for generating images through multiple **AI APIs** in one place.

It supports several generation sources, giving you a wide range of options for creating visual work. The interface is meant to be straightforward: configure settings, run a generation, and review results without jumping between websites and accounts for every backend.

The app also includes a gallery with example requests and images generated from various sources to help you get inspired and start creating quickly.

Whether you need drafts for a creative project or simply want to experiment with AI image generation on your phone, AI Muse gathers the tools in a single Android client.

## What’s inside

- Multiple generation backends for different styles and experiments
- Prompt and parameter controls in one UI
- Gallery of example prompts and results
- Local-friendly workflow focused on creating on-device

## Tech stack

Kotlin · Android · Jetpack Compose · MVVM · Room · REST API

## Status

This project is **no longer actively maintained**. It remains available as a shipped experiment / archive of the idea — useful as a portfolio piece and reference, not as an actively updated product.
